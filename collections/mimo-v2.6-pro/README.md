# MiMo-V2.6-Pro · 100 HTML Files

A collection of **100 self-contained HTML visual studies** generated by **MiMo-V2.6-Pro** — generative art, physics simulations, typography experiments, interfaces and animated scenes. Every piece was created in a **single shot**: one prompt, one pass, one finished file — no revisions, no retries, no post-editing. Each study is a single HTML document with all CSS and JS inline (no external fonts, images or libraries), and ships with its original generation prompt and a rendered screenshot.

**Browse the gallery:** https://miaai-lab.github.io/MiMo-V2.6-Pro-100-HTML-Files/

## Structure

```
├── index.html            ← gallery index (screenshot + description + prompt per study)
├── screenshots/          ← rendered screenshots (001–100, web-optimised JPEG, 1280×800)
├── NNN-*.html            ← the 100 standalone studies
└── NNN-*.txt             ← original prompt, description, techniques and interaction notes
```

## Gallery features

- One card per study: screenshot, number, filename, title, description
- **Open ↗** — loads the piece in a new window/tab
- **Prompt** — opens the original prompt file in a new window/tab
- Live filter across numbers, titles, descriptions and filenames, with a result count
- Self-contained page: inline CSS and JS only, lazy-loaded images, responsive grid, `prefers-reduced-motion` support

## Single-shot generation

Every study in this collection was produced by MiMo-V2.6-Pro in a single generation pass: the model received the brief and returned the complete, final HTML file in one response. Nothing was iterated on, patched or human-corrected afterwards — the 100 files here are exactly what the model emitted. The screenshots in `screenshots/` were captured with headless Chromium (Playwright) at 1280×800 purely for the gallery.

## Rebuilding the gallery

The gallery is plain static HTML — no build step is needed to serve it. Screenshots were captured with Playwright headless Chromium:

```python

page.screenshot(path="screenshots/NNN.jpg", type="jpeg", quality=80)
```
